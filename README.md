# Training Simulator

A third-person action shooter built in Unity where the protagonist must save the village by defeating waves of enemies across a series of escalating levels — all within a single, continuous scene.

---

## 🎮 Concept

The village is under threat, and it's on the protagonist to clear it out, one level at a time. Progression is level-gated: you have to clear Level 1 before Level 2 unlocks, and so on, with all levels built into the same scene rather than separate ones.

---

## 🎮 Features

### Core Gameplay
- **Level progression** — sequential levels that must be cleared in order (Level 1 → Level 2 → ...), all housed within a single scene.
- **Save/Load system** — preserves the player's progress and game state between sessions.
- **Animation blending** — smooth transitions between player movement and combat animations.

### Combat & Items
- **Gun system** — core ranged combat mechanic for taking down enemies.
- **Grenades** — throwable explosives as a secondary combat option.
- **Material-based interactions** — surfaces like **ice** and **mud** affect gameplay (e.g. movement/traction).
- **Inventory system** — manage in-game items and equipment.

### Enemy AI
- Enemy AI to engage and challenge the player across levels.
